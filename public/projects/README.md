# Miniaturas de proyectos

Cada equipo sube aquí la imagen de su proyecto y el sitio la usa solo, sin
tocar código. El nombre del archivo debe ser el `slug` del proyecto
(`src/data/projects.ts`) con extensión `webp`, `avif`, `jpg`, `jpeg` o `png`:

| Proyecto | Archivo esperado |
|---|---|
| The Pumpkin Paradox | `public/projects/the-pumpkin-paradox.webp` |
| Dron autónomo | `public/projects/dron-autonomo.webp` |
| Mini-proyectos Robotics | `public/projects/mini-proyectos-robotics.webp` |
| Dron autónomo (construcción anterior) | `public/projects/dron-autonomo-construccion-anterior.webp` |

- Formato recomendado: horizontal 8:5 (por ejemplo 1600×1000 px), menos de 300 KB.
- Si no hay archivo, la tarjeta muestra el arte animado del área como respaldo.
- Para proyectos nuevos, primero se agrega la entrada en `src/data/projects.ts`
  y después la imagen con el `slug` que se le puso.
- Usa sólo imágenes del propio equipo (capturas, fotos, arte propio): el manual
  de marca pide fotografía real y espontánea, nunca stock.
